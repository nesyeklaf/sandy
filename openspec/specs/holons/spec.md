# Holons

## Purpose
People and agents work on one model of what exists, why, and how it is proven, instead of loose text files.

This capability is generated from the context holon `holons` (Holons).

## Requirements

### Requirement: Contract
The Holons SHALL hold its contract: Every part of the holons work has a Why, a Contract and a Proof, and drift is visible from any level.

#### Scenario: Proof missing
- **WHEN** the contract is checked
- **THEN** no proof is declared, so it is unproven
