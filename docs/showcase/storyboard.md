# Storyboards

Three frames and one benefit sentence per hero. Run the 20 second test on these before a clip is recorded: show the frames and the sentence, ask "What problem does this solve? What could you do next?" A hero passes when 2 of 3 viewers answer both.

## 1. Delegates you can watch

> Hand work to subagents and still see every one of them.

| Frame | Shows |
| --- | --- |
| Problem | A parent thread with a long task; the sidebar shows one thread. |
| Intervention | The agent starts three delegates: scout, implementer, reviewer. |
| Result | The sidebar nests the three children under the parent, each with its live status; one click opens a child. |

## 2. Stages that hold the agent

> The agent works in stages, and a stage decides which tools it may use.

| Frame | Shows |
| --- | --- |
| Problem | Planning stage active; the agent wants to edit a file right away. |
| Intervention | The edit call comes back blocked: "stage plan does not allow edit". |
| Result | The agent submits the plan instead, the owner approves, the stage moves to build and the edit goes through. |

## 3. Topics on the rail

> Find your way back in a thread with hundreds of messages.

| Frame | Shows |
| --- | --- |
| Problem | A long thread, scrolled far down; the rail is a column of ticks. |
| Intervention | Hovering the rail opens the topic list; the brackets mark each topic's range. |
| Result | A click on a topic jumps to its first message. |

## 4. Every connection, named

> Know every host your agent IDE talks to.

| Frame | Shows |
| --- | --- |
| Problem | An IDE that runs agents, and no idea where it phones. |
| Intervention | Settings, Connections: each destination with its purpose and last contact. |
| Result | An unknown host appears and the overview turns red. |

## 5. Answers you can use

> The agent answers with a plan to approve and a form to fill, not a wall of text.

| Frame | Shows |
| --- | --- |
| Problem | A question with options, answered as a long paragraph. |
| Intervention | The same answer as a card: a plan with steps and a form with two choices. |
| Result | The owner ticks the choices; the picks go back to the agent as the next message. |
