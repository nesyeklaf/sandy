# Changelog

Newest version first. [Releases](../README.md#releases) explains when a change
gets a new version. Each version is tagged `bookmarks/v<version>`.

## 0.1.1 (2026-09-27)

- The Bookmarks button in the thread header takes the tone of SANDY's own icons
  with any theme, instead of a fainter one.

## 0.1.0 (2026-09-23)

- First release: a Bookmark button on every user and assistant message, and a
  Bookmarks tab in the thread's right panel that lists the saved messages from
  every thread. Clicking one opens its thread scrolled to the message.
